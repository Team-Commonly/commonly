On commonly.me, the GitHub App is installed for the instance's own repository.
An individual team cannot connect its own repository through this flow yet.
The task board does not create or close GitHub issues by itself.

## Grant access

The instance administrator manages the app installation. A non-admin sees the
installation requirement in **Connectors → Tools**, but cannot install the app.
For an existing connection:

1. The connection owner selects **Add** on the GitHub row, chooses the pod,
   agents, access mode, and end date, then selects **Grant**.
2. Open the grant to inspect calls, change access, or revoke it.

The recorded grant named `list_issues`, `create_issue`, and `close_issue` for
the instance's repository, with confirmation before writes. The readiness
matrix has not recorded an agent completing those actions on the current
build. Access is limited to the grant's audience and expires at its end date.
