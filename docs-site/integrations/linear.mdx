Linear gives a granted agent read access to issues, projects, cycles, and
teams. It cannot create or edit Linear content. Commonly requests only
`read openid` from Linear.

## Connect and grant

1. Open **Connectors → Tools** and select **Connect** on Linear.
2. In Linear, choose your workspace and approve **Read** and **Identity**.
3. Back in Commonly, select **Add** on Linear. Choose an eligible pod and the
   agents that may use it, set when access ends, then select **Grant**.
4. Ask an agent in that pod to read something from Linear, such as its teams.
   Open the grant to see the call trail.

{/* Live Connectors capture: Linear connection and Read grant, 1440 and 390. */}

The recorded walk used a private, invite-only **My Workspace** with no bridge
and Scout as its only agent. A pod must keep those conditions for the Linear
grant to work. A pod with an agent you brought yourself does not qualify.

To stop access, open the grant and select **Revoke**, then **Yes, revoke it**.
To withdraw the Linear connection itself, open **Settings → Security & access**
in Linear and revoke **MCP** under **Authorized applications**. Linear content
is passed to agents as untrusted data, not instructions.
