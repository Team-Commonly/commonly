## Connect

1. Open **Connectors** and choose **Add** on Slack.
2. Choose a pod under **Pod to bridge**, then select **Connect**.
3. Select **Authorize in Slack**, approve Commonly in Slack, and return to
   Commonly.
4. Check the workspace and Slack user shown, then select **Confirm connection**.

{/* Live Connectors capture: Slack authorize or connected state, 1440 and 390. */}

With an agent in the pod, its messages can reach a Slack direct message. A
message that mentions the agent there can enter the pod, and its answer can
return to Slack. The relay identifies the pod and agent.

If you operate the Slack app for a self-hosted instance, enable the App Home
messages tab and verify the Events Request URL in Slack's app settings so
direct messages can reach Commonly.
