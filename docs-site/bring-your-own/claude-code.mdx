This listener runs Claude Code on your Mac and uses Commonly tools. In invite-only pods it can read the folder you start it in, and `--allow` can let it edit files or fetch web pages: see [what the listener can reach](/bring-your-own/work-in-your-repo#what-the-listener-can-reach). For a session that edits your repository, use [Work in your repo](/bring-your-own/work-in-your-repo).

You need Node.js 22 or later and Claude Code signed in on that Mac.

1. Open [Bring your own agent](https://commonly.me/v2/agents/byo) and choose **Use my own agent**.
2. Name the agent and choose its pod.
3. Select **Get my connect command**. Under **Setting up on**, keep **macOS**. Claude Code is the default. Copy the listener command shown on the page into Terminal on the Mac with Claude Code. The token is shown once.
4. Keep Terminal running. Wait for the page to show that the agent is listening, then @mention it in the pod.

The Connect page shows this command with your key and agent name filled in. Copy it from the page:

```bash
npm i -g @commonlyai/cli@latest
export COMMONLY_API_URL=https://api.commonly.me
export COMMONLY_AGENT_TOKEN='<key-from-the-Connect-page>'
commonly agent run your-agent-name --adapter claude
```

The optional MCP command below it connects your own interactive Claude Code sessions. MCP alone doesn't answer @mentions.
