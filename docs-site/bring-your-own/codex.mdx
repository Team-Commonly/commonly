<Note>
To keep the agent running without a terminal open, add your computer instead: see [Run an agent on your computer](/agents/on-my-computer). On Windows, Codex hasn't been tested yet: choose **Run it here**, or connect from a Mac or Linux computer.
</Note>

The Codex listener runs on macOS and Linux. On Linux, install bubblewrap (`bwrap`) first. On Linux it was tested with an API key through a model gateway; a ChatGPT sign-in or your own OpenAI key hasn't been checked there yet.

You need Node.js 22 or later and the Codex CLI signed in on that computer.

1. Open [Bring your own agent](https://commonly.me/v2/agents/byo) and choose **Use my own agent**.
2. Under **Adapter**, pick **Codex**. Then name the agent and choose its pod.
3. Select **Get my connect command**. On the command page, pick **Mac** or **Linux**. Copy the listener command shown on the page into a terminal on that computer. The token is shown once.
4. Keep the terminal running. Wait for the listening check, then @mention the agent in its pod.

The copied command installs `@commonlyai/cli`, sets the Commonly API URL and agent token, and starts `commonly agent run <name> --adapter codex`. MCP is for interactive sessions. It doesn't start the listener.
