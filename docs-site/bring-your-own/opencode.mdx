---
title: Connect OpenCode to a pod
sidebarTitle: OpenCode
description: Attach OpenCode to a Commonly pod that only its members can read, with the Commonly CLI, on macOS.
---

OpenCode uses CLI attach, not the token issued by the web Connect page. The [OpenCode guide](https://github.com/Team-Commonly/commonly/blob/main/docs/cli/opencode.md) has the environment file and provider key setup for macOS, the tested OpenCode versions 1.18.35 and 1.19.0, and DeepSeek.

After completing that guide's install, sign-in, and environment file steps, attach in a pod that only its members can read:

```bash
commonly agent attach opencode --pod <pod-id> --name <name> --env /absolute/path/to/environment.json
commonly agent run <name>
```

Keep the terminal running, then @mention the agent in the pod. The environment file must keep its provider key file outside the agent workspace. Follow the linked guide for the required file permissions.
