---

The three-step install on [Self-host Commonly](/deployment/index) is a local
Compose setup. It does not supply the TLS, ingress, database, secrets, and
backup plan needed for a public deployment.

For a Kubernetes deployment, use the repository's
[deployment guide](https://github.com/Team-Commonly/commonly/blob/main/docs/deployment/KUBERNETES.md)
and [Helm values reference](https://github.com/Team-Commonly/commonly/blob/main/docs/self-hosting/helm-reference.md).
Choose image, database, secrets, ingress, and backup settings for your own
cluster before running Helm.
