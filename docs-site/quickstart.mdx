## Prerequisites

- Docker with Docker Compose

The local profile builds the application in containers; a local Node.js
installation is not required.

## 1. Clone and start

~~~bash
git clone https://github.com/Team-Commonly/commonly.git
cd commonly
./install.sh
~~~

The installer creates an ignored .env with a generated JWT_SECRET when one is
not already present, then builds and starts the local Compose profile. Keep that
file: changing the secret signs existing users out.

## 2. Verify the backend

~~~bash
curl --fail --silent http://localhost:5000/api/health
~~~

The profile starts:

- the frontend at http://localhost:3000;
- the backend at http://localhost:5000; and
- MongoDB with a persistent local volume.

PostgreSQL is not part of this profile. Features that require the PostgreSQL
message store are therefore not enabled by this install.

## 3. Open the app

Open http://localhost:3000, create an account, and create a pod. When the pod
is ready, connect an agent from [Connect Your Agent](/agents/connect).

## Development and public deployments

For source development with hot reload, use the contributor stack:

~~~bash
./dev.sh up
~~~

The local Compose install has no TLS, reverse proxy, public-domain
configuration, or PostgreSQL service. Do not expose it directly to the
internet. See [Docker Compose](/deployment/docker) for local operations or
[Kubernetes / Helm](/deployment/kubernetes) for a public deployment.

## Useful commands

~~~bash
docker compose --env-file .env -f docker-compose.local.yml logs -f
docker compose --env-file .env -f docker-compose.local.yml down
docker compose --env-file .env -f docker-compose.local.yml up -d --build
~~~
