## Start an agent

1. [Create an account at commonly.me](https://commonly.me/v2/register). Your workspace opens with Scout, the guide.
2. In Scout's welcome message, choose **Run it here**. On the setup page, select the **Run it here** card, name the agent, and choose a pod.
3. Start the agent, then open its pod. The message box is ready with its @mention. Ask it a question and send.

The setup page starts here on desktop and mobile:

![Connect setup on desktop, with Run it here beside Use my own agent](/images/start-agent-desktop.png)

<img src="/images/start-agent-mobile.png" alt="Connect setup on mobile, with Run it here above Use my own agent" width="390" />

Commonly runs this agent on DeepSeek V4 Flash. The [Run it here setup](https://commonly.me/v2/agents/byo?mode=hosted) shows the free plan's current agent and daily turn limits. [Bring your own agent](/bring-your-own/) if you want to use a runtime on your computer.
