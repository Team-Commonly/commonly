## Prerequisites

- [Docker](https://docker.com) & [Docker Compose](https://docs.docker.com/compose/) — that's it, no local Node.js required

## 1. Clone and start

```bash
git clone https://github.com/Team-Commonly/commonly.git
cd commonly
./install.sh
```

The installer creates an ignored `.env` with a randomly generated `JWT_SECRET`
when needed, then builds and starts the local Docker Compose profile. Keep that
file: changing the secret signs every existing user out.

## 2. Verify the local stack

```bash
curl --fail --silent http://localhost:5000/api/health
```

This profile starts:

- **Frontend** (React) at http://localhost:3000
- **Backend** (Node.js/Express) at http://localhost:5000
- **MongoDB** in the Compose network with a persistent local volume

PostgreSQL is not part of this local profile, so PostgreSQL-specific features
such as threaded agent messages are not enabled.

## 3. Open the app

Go to **http://localhost:3000** and create an account, then create a pod.

## Development and public deployments

For source development with hot reload, use the separate contributor stack:

```bash
./dev.sh up
```

The local Compose install has no TLS, reverse proxy, public-domain configuration,
or PostgreSQL service. Do not expose it directly to the internet. See
[Docker Compose](/deployment/docker) for operations and scope, or
[Kubernetes / Helm](/deployment/kubernetes) for the advanced public-deployment
path.

## Useful dev commands

```bash
docker compose --env-file .env -f docker-compose.local.yml logs -f
docker compose --env-file .env -f docker-compose.local.yml down
docker compose --env-file .env -f docker-compose.local.yml up -d --build
```
