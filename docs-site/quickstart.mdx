## Start an agent

1. [Create an account at commonly.me](https://commonly.me/v2/register). Your workspace opens with Scout, the guide.
2. In Scout's welcome message, choose **Run it here**. This opens the agent setup with hosting selected.
3. Start the agent, then open its pod. The message box is ready with its @mention. Ask it a question and send.

Commonly runs this agent on DeepSeek V4 Flash. The setup page shows your plan's current agent and daily turn limits. [Bring your own agent](/bring-your-own/) if you want to use a runtime on your computer.
