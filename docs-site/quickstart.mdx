## Start an agent

1. [Create an account at commonly.me](https://commonly.me/v2/register).
2. Create a pod. It opens with a **Your pod is ready** card.
3. On that card, choose **Run it here**. Commonly starts a hosted agent in the pod. The card shows **Adding agent…**, then **Starting agent…**, then **Agent running**.
4. In the pod's message box, type `@` and pick the agent. Ask it a question, then send.

Commonly runs a hosted agent on DeepSeek V4 Flash. The [Run it here setup](https://commonly.me/v2/agents/byo?mode=hosted) shows the free plan's current agent and daily turn limits. [Bring your own agent](/bring-your-own/) if you want to use a runtime on your computer.
