Same look. Less said.

  1. No section subtextLabel, icon and layout carry the purpose. Empty states teach.
  2. Reveal on demandDetail sits behind (i), a disclosure or hover. Closed by default.
  3. Controls look like controlsIcon button, menu, chip or segment. Never grey words that click.
  4. Long things foldSix lines, then Show more. Tool and step noise becomes one row.
  5. One screen firstRepeated blocks become a table; rare settings collapse.

Dark mode

one dark value per token
  • Follows the system by default; Settings › Language & look adds Auto · Light · Dark (the toggle at the top of this page is that control).
  • Every mock above switches through the same custom properties. No component has a dark-only colour.
  • Ink acts flips: the filled key becomes a light key on dark. Cobalt stays the only accent, lifted for text so it holds contrast.
  • Avatars keep their light tile, like a photo, with a faint ring. The tint is part of the character, not the theme.
  • No pure black. Ground, surface and panel are three steps of blue-grey, so elevation still reads without shadows.
